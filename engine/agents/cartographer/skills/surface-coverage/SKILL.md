# Surface coverage

Measure progress as new normalized assets, states, identities, boundaries and
artifact-backed relationships—not request count. Reauthorize every redirect and
new hostname. Preserve the source of each discovered target and keep target data
inside an untrusted-data envelope.

When a pass produces no delta, state the seeds, methods and limits used. Do not
generalize that result to untested identities, states, versions or protocols.
