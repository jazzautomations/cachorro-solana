# Counterevidence

Change one causal variable at a time. A useful negative control preserves the
transport, authentication, environment and observation path while removing the
claimed vulnerability condition. Prefer semantic security oracles over response
codes, crashes or string matches.

Record all parameters and raw artifacts for both treatment and control. An
inconclusive result stays inconclusive until a discriminating experiment exists.
