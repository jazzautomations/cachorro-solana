# Toolpacks

Toolpacks are pinned external sensors, analyzers, generators and oracles. They
are not agents and their output is never a finding by itself.

An adapter is eligible only when it:

1. creates distinct reachability or semantic information;
2. emits structured, provenance-linked artifacts;
3. supports deterministic replay or a measurable feedback signal;
4. declares target side effects and resource bounds;
5. has a reviewed license and isolation strategy.

The registry is a research backlog, not an install script. `planned` entries
must not be executed until an adapter, policy and eval fixture exist. Copyleft or
mixed-license projects remain external processes/containers unless a deliberate
licensing decision says otherwise.
